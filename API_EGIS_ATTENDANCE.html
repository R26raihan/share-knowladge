Slip Gaji

Melihat daftar slip pegawai yang login dan mengunduh laporan PDF per periode.

PAYROLL
MethodEndpointParameter / kegunaan
GET/api/v1/payroll/payslipsDaftar slip pengguna. Query opsional year, month, state; pagination page (default 1) dan per_page (default 20).
GET/api/v1/payroll/payslip/downloadUnduh PDF. Query month, year, format (default pdf); response berupa bytes PDF.

Riwayat Hidup

Layar aplikasi menampilkan dokumen resume/PDF yang diberikan sebagai file lokal atau URL.

BELUM LENGKAP

Belum ada endpoint aktif yang dapat didokumentasikan dari alur layar. Endpoint legacy sap/cv masih tercantum di konfigurasi client, tetapi tidak ditemukan pemanggil aktifnya; endpoint tersebut tidak dicatat sebagai API Odoo v1.

Pengajuan izin sampai persetujuan

Daftar jenis izin, membuat pengajuan, memantau daftar izin, dan memproses approval/rejection.

03
MethodEndpointParameter / kegunaan
GET/api/v1/submissions/typesDaftar jenis izin/pengajuan yang tersedia.
GET/api/v1/submissionsDaftar pengajuan. Filter opsional: state, date_from, date_to.
POST/api/v1/submissionsMembuat pengajuan izin.
GET/api/v1/submissions/need-approvalDaftar pengajuan untuk approver. Filter opsional tanggal.
POST/api/v1/submissions/approvalApprove atau reject pengajuan oleh reviewer.
POST/api/v1/submissions/{id}/refuseMenolak/membatalkan pengajuan melalui aksi pemohon.

Body membuat pengajuan

{
  "alasan_pengajuan_code": "IZIN",
  "tanggal_mulai": "2026-10-28",
  "tanggal_selesai": "2026-10-28",
  "keterangan": "Keperluan keluarga",
  "latitude": -6.2,
  "longitude": 106.8,
  "location_address": "Jakarta"
}

Body approval

{
  "id_submission": 82,
  "action": "APPROVE",
  "keterangan_reviewer": "Disetujui"
}

Untuk reject reviewer, gunakan action: "REFUSE". Field lokasi bersifat opsional pada body pembuatan.

Lembur dan FPKT

Daftar, pengajuan, detail lembur, serta unduh Formulir Perintah Kerja Tambahan.

06
MethodEndpointKegunaan
GET/api/v1/overtime/lihatDaftar lembur.
GET/api/v1/overtime/employee-tad/{employee_id}Kuota dan daftar lembur operator TAD.
GET/api/v1/overtime/datapegawaiData pegawai untuk form pengajuan.
GET/api/v1/overtime/detail/{overtime_id}Detail pengajuan dan operator lembur.
POST/api/v1/overtime/simpanMembuat pengajuan JSON.
POST/api/v1/overtime/uploadUnggah lampiran multipart.
GET/api/v1/overtime/{overtime_id}/fpkt/download?format=pdfUnduh PDF FPKT. Tombol TAD memanggil API ini; tidak menggunakan URL assignment_letter.
GET/api/v1/overtime/{overtime_id}/download?format=pdfEndpoint download Surat Tugas yang masih didefinisikan client.

Backend juga mendokumentasikan bentuk /api/v1/overtime/fpkt/download dengan query overtime_id saat ID tidak tersedia pada path. Operator yang tercantum menerima lembar sendiri; parameter employee_id hanya untuk Manager/Koordinator/HR sesuai hak akses backend.

Header request

Header umum yang disiapkan client EGIS oleh Dio interceptor.

AUTH
Authorization: Bearer {access_token}
Accept: application/json
Content-Type: application/json
App-Source: IOFFICE_ANDROID

Unduhan FPKT memakai Accept: application/pdf. Jangan menyalin token atau URL file bertanda tangan dari log ke dokumen.
