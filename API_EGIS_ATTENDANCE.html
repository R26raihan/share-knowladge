EGIS · API reference

Attendance,
per fitur.

Referensi endpoint Odoo ber-prefix /api/v1/ yang dipakai fitur attendance EGIS, dikelompokkan sesuai alur kerja pengguna.

Flutter mobileAuth: Bearer tokenApp-Source: IOFFICE_ANDROID

Fitur

PresensiRiwayat & detailKoreksi kehadiranKehadiran timLembur & FPKT
Cakupan: hanya endpoint Odoo dengan prefix /api/v1/. Path ditulis relatif terhadap base URL environment EGIS. Endpoint lama Flutter yang tidak memakai namespace ini tidak dicantumkan di halaman ini.

Presensi harian

Validasi lokasi, unggah foto, dan kirim proses presensi masuk/pulang.

01
MethodEndpointKegunaan / data
POST/api/v1/absensi/upload-photoUnggah foto sebagai multipart field photo.
POST/api/v1/absensi/prosesProses presensi Odoo dengan payload dari alur absensi.

Payload lokasi dan presensi dikirim sebagai JSON dari client; foto dikirim sebagai multipart/form-data.

Riwayat, kalender, dan detail kehadiran

Memuat jadwal bulanan, rekap riwayat, dan detail satu hari untuk pengguna.

02
MethodEndpointParameter / kegunaan
GET/api/v1/absensi/jadwal_bulanan/{idPegawai}Query bulan dan tahun.

Koreksi kehadiran

Mengajukan koreksi, mengelola dokumen, dan memproses persetujuan.

03
MethodEndpointParameter / kegunaan
GET/api/v1/absensi/koreksiQuery opsional employee_id, tanggal.
POST/api/v1/absensi/koreksiMembuat pengajuan koreksi.
POST/api/v1/absensi/koreksi/upload-documentUnggah dokumen pendukung.
POST/api/v1/absensi/koreksi/{id}/action/{approve|reject}Persetujuan atau penolakan; reject dapat menyertakan rejectedReason.

Rekap kehadiran unit dan detail presensi anggota tim.

GET/api/v1/attendance/detail?idpegawai={id}[&tanggal={date}]Detail kehadiran anggota tim. Tanggal opsional.

Lembur dan FPKT

Daftar, pengajuan, detail lembur, serta unduh Formulir Perintah Kerja Tambahan.

05
MethodEndpointKegunaan
GET/api/v1/overtime/lihatDaftar lembur.
GET/api/v1/overtime/employee-tad/{employee_id}Kuota dan daftar lembur operator TAD.
GET/api/v1/overtime/datapegawaiData pegawai untuk form pengajuan.
GET/api/v1/overtime/detail/{overtime_id}Detail pengajuan dan operator lembur.
POST/api/v1/overtime/simpanMembuat pengajuan JSON.
POST/api/v1/overtime/uploadUnggah lampiran multipart.
GET/api/v1/overtime/{overtime_id}/fpkt/download?format=pdfUnduh PDF FPKT. Tombol TAD memanggil API ini; tidak menggunakan URL assignment_letter.
GET/api/v1/overtime/{overtime_id}/download?format=pdfEndpoint download Surat Tugas yang masih didefinisikan client.

Backend juga mendokumentasikan bentuk /api/v1/overtime/fpkt/download dengan query overtime_id saat ID tidak tersedia pada path. Operator yang tercantum menerima lembar sendiri; parameter employee_id hanya untuk Manager/Koordinator/HR sesuai hak akses backend.

Header request

Header umum yang disiapkan client EGIS oleh Dio interceptor.

AUTH
Authorization: Bearer {access_token}
Accept: application/json
Content-Type: application/json
App-Source: IOFFICE_ANDROID

Unduhan FPKT memakai Accept: application/pdf. Jangan menyalin token atau URL file bertanda tangan dari log ke dokumen.

Sumber implementasi: lib/core/network/api/attendance/, lib/core/network/api/overtime/, dan layar fitur attendance EGIS. Buka catatan API lembur versi Markdown.
